VPC 서브넷 3유형 & Transit Gateway

어디까지 통신 가능한가로 서브넷을 나눈다
Private

내부 전용

  • VPC 내부 통신만
  • 외부 노출 없음(보안)
  • DB·백엔드 등
External

외부 연결

  • 외부(북/남) 트래픽 허용
  • LoadBalancer·공인 접근
  • 프론트엔드·게이트웨이
Private TGW

크로스 VPC

  • Transit Gateway 경유
  • 다른 VPC와 통신
  • 공유 서비스 접근

라이브 실습 — Supervisor & VPC 탐색

환경 확인부터 서비스 노출까지
# Supervisor 환경 확인 $ kubectl config get-contexts # Supervisor context $ kubectl get ns # vSphere Namespace 목록 $ kubectl get cluster -A # TKG/VKS 클러스터 # VPC 네트워킹 구조 탐색 $ kubectl get networkconfig -A $ kubectl expose pod vpc-test --type=LoadBalancer --port=80 -n <ns> $ kubectl get svc -n <ns> # External IP 확인
