  • 하이브리드 파이프라인 — Jenkins(CI) + ArgoCD(CD)를 종합 프로젝트로 구축한다

GitOps & ArgoCD

Git이 유일한 진실의 원천(Single Source of Truth)
  • 선언적 — 원하는 상태를 Git 매니페스트로 기술
  • 버전 관리 — 모든 변경이 Git 이력 · git revert = 롤백
  • 자동 동기화 — ArgoCD가 Git ↔ 클러스터 차이를 감지·조정
  • 지속 조정(Self-Heal) — 수동 변경(Drift)도 원래 상태로 복구
i
ArgoCD Application CR: source(Git repo/path) + destination(cluster/ns) + syncPolicy(automated: prune·selfHeal)

라이브 실습 — 파이프라인 구성요소

Harbor·Trivy → Jenkins → ArgoCD 순서로
# Part A: Harbor 자격증명 + Trivy 스캔 $ kubectl create secret docker-registry harbor-cred \ --docker-server=harbor.example.com --docker-username=admin --docker-password=<pw> $ trivy image --severity HIGH,CRITICAL nginx:1.24 # Part B: Jenkins 설치 (Helm) $ helm install jenkins jenkins/jenkins -n jenkins --create-namespace --set agent.enabled=true # Part C: ArgoCD 설치 + Application 등록 $ kubectl apply -n argocd -f https://.../argo-cd/stable/manifests/install.yaml $ kubectl apply -f application.yaml # syncPolicy: automated(prune,selfHeal)

종합 프로젝트 — GitOps Capstone

지금까지 배운 것을 하나의 파이프라인으로
  • 저장소 분리 — App Repo + Manifest Repo
  • CI(Jenkins) — 빌드 + Trivy 스캔 + Harbor push + Manifest Repo에 image tag commit
  • CD(ArgoCD) — Manifest Repo watch → 자동 sync (ApplicationSet로 dev/stage 분리)
  • RBAC — 개발자는 dev NS만, ArgoCD는 dev+stage
