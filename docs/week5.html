AccessMode & StatefulSet

어떻게 붙이나, 그리고 상태 있는 워크로드
AccessMode

볼륨 접근 방식

  • RWO (ReadWriteOnce) — 단일 노드 읽기·쓰기
  • ROX (ReadOnlyMany) — 다중 노드 읽기
  • RWX (ReadWriteMany) — 다중 노드 읽기·쓰기(NFS 등)
  • RWOP — 단일 Pod 전용
StatefulSet

vs Deployment

  • 안정적 ID — pod-0, pod-1 순서 보장
  • Headless Service로 각 Pod에 고유 DNS
  • volumeClaimTemplates — Pod별 전용 PVC
  • → DB·메시지큐 등 상태 워크로드
