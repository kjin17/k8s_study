Pod 생명주기 & Probe

상태를 알고, 헬스체크로 자동 복구·트래픽 제어
Lifecycle

Pod 5가지 상태

  • Pending — 스케줄/이미지 pull 대기
  • Running — 컨테이너 정상 실행 중
  • Succeeded / Failed — 정상/비정상 종료
  • Unknown — 노드 통신 불가
  • 재시작 정책: Always · OnFailure · Never
Probe

Liveness vs Readiness

  • Liveness — 실패 시 컨테이너 재시작
  • Readiness — 실패 시 Service에서 제외(트래픽 차단)
  • 방식: httpGet · tcpSocket · exec
  • → 자동 복구 + 무중단 트래픽 라우팅

라이브 실습 — 핵심 오브젝트 & 트러블슈팅

스크립트로 학습하고, 워커에서 직접 진단
