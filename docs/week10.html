라이브 실습 — 프로비저닝 & 접근

Cluster CRD 하나로 클러스터를 만든다
apiVersion: cluster.x-k8s.io/v1beta1 kind: Cluster metadata: {name: dev-cluster, namespace: dev-ns} spec: topology: class: tanzukubernetescluster version: v1.28.4+vmware.1-tkg.1 controlPlane: {replicas: 3} workers: {machineDeployments: [{name: worker-pool, replicas: 3}]} $ kubectl get cluster,machine -n dev-ns $ kubectl get secret dev-cluster-kubeconfig -n dev-ns -o jsonpath='{.data.value}' | base64 -d > kc

라이브 실습 — 노드 풀 스케일링

선언만 바꾸면 CAPI가 조정
# worker-pool을 3 → 5로 스케일 아웃 $ kubectl patch cluster dev-cluster -n dev-ns --type merge -p ' spec: topology: workers: machineDeployments: - {class: node-pool, name: worker-pool, replicas: 5}' $ kubectl --kubeconfig=kc get nodes # 워크로드 클러스터 노드 확인
i
